# shop.asparagents.com chrome

`shop-chrome.php` is the Code Snippets snippet "asparagents header, footer and colours" on shop.asparagents.com
(front end only). It prints the same header, footer and WhatsApp button as asparagents.com, adds the site colours
and button style to WooCommerce, and hides the old Oxygen header, footer and floating menu.

The header and footer are copies of the static site markup. When the main menu or footer changes, update this
file and paste it into the snippet again.
